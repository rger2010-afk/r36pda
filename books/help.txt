Добро пожаловать в r36pda!
Это твой карманный компьютер на R36S.

Встроенные приложения:
- Терминал — команды Linux, подсказки по Tab
- Файлы — двухпанельный FAR-менеджер (F9 - меню)
- Система — сведения об устройстве
- Процессы — список задач
- Калькулятор
- Настройки — кнопки, курсор, сброс
- Python — редактор и запуск своих программ
- Записки — текстовые заметки
- Контакты — адресная книга
- Календарь — события по дням
- Задачи — список дел
- Рисование — перо со стика
- Читалка — книги из папки books

Положи свои .txt книги в папку books и открывай их здесь.

Управление:
- Стик — курсор/выбор
- A — выбрать/ввести
- B — назад/удалить
- Select — дополнительное действие
- Start — запуск/сохранить
- Fn+A/B — выйти из приложения
