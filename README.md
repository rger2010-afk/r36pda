# r36pda — превращаем R36S в карманный КПК-десктоп

PDA-лаунчер (Palm/WinMobile-стиль) для R36S: сетка иконок, навигация
джойстиком, статус-бар с часами/батареей. Кодинг, ардуино, игры — из одного
меню. C++17 + SDL2, без внешних зависимостей (встроенный шрифт font.h).

## Структура

```
r36pda/
├── src/
│   ├── main.cpp      — лаунчер (SDL2)
│   └── font.h        — встроенный 5x7 пиксельный шрифт (лат + кириллица)
├── config/
│   └── apps.cfg      — список приложений: имя | команда | R,G,B
├── apps/             — шелл-обёртки (терминал, ардуино, игры, файлы, калькулятор)
├── Makefile          — сборка на R36S / Linux
└── Makefile.win      — сборка на ПК (MinGW + SDL2)
```

## Сборка на R36S (ArkOS)

```sh
sudo apt-get install --reinstall g++ libsdl2-dev   # один раз
make
make install        # копирует в ~/r36pda
cd ~/r36pda && ./r36pda
```

Полный экран: `R36PDA_FULLSCREEN=1 ./r36pda`
(на консоли 640x480 — экран и так совпадает).

## Сборка на ПК (Windows + MinGW + SDL2)

Требуется MinGW-w64 и SDL2 для mingw. Путь к SDL2 задаётся в Makefile.win
(переменная SDL2DIR). `SDL2.dll` должен лежать рядом с r36pda.exe.

## Собрать через GitHub (готовый пакет без установки ничего)

1. Создай пустой репозиторий на GitHub (публичный или приватный).
2. Зальёшь в него этот проект (см. ниже).
3. GitHub Actions сам соберёт `r36pda-port` под aarch64 (R36S).
4. На странице репозитория: **Actions** → последний запуск → артефакт
   **r36pda-port** → скачай и распакуй.
5. Скопируй содержимое папки на SD-карту в `/roms/ports/` — готово.

Залить проект в GitHub:

```sh
cd r36pda
git init
git add .
git commit -m "r36pda: PDA launcher for R36S"
git branch -M main
git remote add origin https://github.com/<ТВОЙ_ЮЗЕР>/<РЕПО>.git
git push -u origin main
```

Сборка запустится автоматически после пуша. Скачанный `r36pda-port`
работает на любом R36S офлайн — это и есть «скинул и запустил».

## Управление

- **Джойстик**: D-Pad/стики — движение, A/B — запуск, Fn+Start — выход
- **Клавиатура**: стрелки/WASD, Enter — запуск, F1 — в эмулятор, Esc — выход
- **Игры**: иконка «Игры» возвращает в EmulationStation

## Добавить приложение

Редактируй `apps.cfg`:

```
Моё приложение | путь/команда | 100,200,150
```

Команда выполняется через `/bin/sh -c` (Linux) или `cmd /c` (Windows).

## Ардуино

На консоли:

```sh
sudo apt install arduino-cli
arduino-cli core install arduino:avr
```

После этого иконка «Ардуино» в лаунчере показывает рабочий скрипт
(список скетчей в ~/sketches, команды compile/upload).
